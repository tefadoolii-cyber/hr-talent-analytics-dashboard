# 📊 وِصال — Wisal HR | منصة تحليل وإدارة الكوادر المهنية

**وِصال — Wisal HR** هي لوحة تحكم تفاعلية متطورة لإدارة وتحليل بيانات الكوادر والكفاءات البشرية، مبنية لدعم اتخاذ القرار وتسهيل فرز السير الذاتية وإدارة المواهب وفق أعلى معايير الأمان وتجربة المستخدم.

---

## 🔒 حماية الدخول بكلمة مرور (Password Protection):
- المنصة محمية بشاشة تسجيل دخول أنيقة تمنع الوصول غير المصرح به.
- **كلمة المرور الافتراضية**: `wisal2026`
- إمكانية تذكر تسجيل الدخول (Remember Me).
- خيار تغيير كلمة المرور في أي وقت مباشرة من شريط التحكم العلوي.
- زر قفل / تسجيل خروج فوري بضغطة زر واحدة.

---

## 🌟 أبرز المميزات (Key Features):

1. **📊 بطاقات مؤشرات أداء تفاعلية (Real-time KPIs)**:
   - إجمالي عدد الكوادر المسجلة.
   - متوسط سنوات وشهور الخبرة.
   - توزيع الجنس (ذكور / إناث) والنسب المئوية.
   - حاملو الرخص المهنية والاعتمادات.
   - ذوو الخبرات الإضافية، وأكثر التخصصات شيوعاً.

2. **📈 مخططات بيانية تحليلية ديناميكية (Chart.js)**:
   - مخطط توزيع المؤهلات العلمية (دونات).
   - مخطط فئات سنوات الخبرة (بدون خبرة، 1-2 سنة، 3-5، 6-9، 10+).
   - مخطط أعلى التخصصات الأكثر طلباً.
   - مخطط المسميات الوظيفية المقترحة.
   - مخطط نسبة حاملي الرخص والاعتمادات المهنية.

3. **📄 محرك ذكي لقراءة واستخراج بيانات السير الذاتية (PDF Parser)**:
   - استخراج بيانات السيرة الذاتية عبر مكتبة **Mozilla PDF.js**.
   - التعرف الآلي على (الهوية، الجنس، المؤهل، التخصص، الدورات والشهادات، سنوات الخبرة ومجالاتها، الرخص المهنية، المسمى المقترح).
   - نافذة مراجعة وتعديل البيانات قبل اعتمادها.

4. **📁 استيراد وتصدير ملفات الإكسيل (Excel Integration)**:
   - استيراد وتصدير بصيغ (`.xlsx`, `.xls`, `.csv`).
   - دعم السحب والإفلات (Drag & Drop).
   - **الدمج الذكي (Smart Merge)**: الحفاظ الكامل على البيانات السابقة دون حذف عند استيراد أي ملف جديد، وتحديث السجلات القائمة بناءً على رقم الهوية.
   - **الضبط التلقائي للخبرات**: في حال عدم وجود خبرات أو حداثة التخرج، يتم وضع `0` صراحة لكافة الحقول الإحصائية والفرعية.

5. **🔍 تصفية وفلاتر متعددة الأبعاد (Advanced Filters)**:
   - بحث فوري شامل في كافة الحقول.
   - فلترة حسب الجنس، المؤهل، التخصص، المسمى الوظيفي.
   - فلترة حسب الرخص المهنية ووجود خبرات إضافية.
   - نطاق سنوات الخبرة (من - إلى).
   - فلترة الدورات والشهادات (قائمة منسدلة + بحث نصي حر).

6. **👤 بطاقة الملف الكامل للمرشح (Candidate Profile Card)**:
   - عرض شامل لكافة الحقول الـ 15 بتصميم بطاقة عصرية وسهلة القراءة.

---

## 🛠️ التقنيات المستخدمة (Tech Stack):

- **HTML5 & CSS3** (RTL Arabic Support)
- **Tailwind CSS** (تصميم عصري ومتجاوب)
- **Chart.js** (رسوم بيانية تفاعلية)
- **SheetJS (xlsx)** (معالجة وقراءة وتصدير ملفات الإكسيل)
- **Mozilla PDF.js** (استخراج النصوص والبيانات من ملفات الـ PDF)
- **FontAwesome 6** (أيقونات واجهة المستخدم)
- **Node.js** (خادم محلي خفيف)

## 🚀 طريقة التشغيل (Quick Start):

### الطريقة الأولى: التشغيل عبر خادم Node.js
```bash
# تثبيت الاعتماديات
npm install

# تشغيل الخادم المحلي
npm start
```
ثم افتح المتصفح على: `http://localhost:3000`  
كلمة المرور الافتراضية للدخول: `wisal2026`

### الطريقة الثانية: الفتح المباشر
يمكنك فتح ملف `index.html` مباشرة في أي متصفح حديث دون الحاجة لأي إعدادات إضافية.
